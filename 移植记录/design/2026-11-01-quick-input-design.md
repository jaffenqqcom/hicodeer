# 快捷输入（Quick Input）设计

日期：2026-11-01
范围：`crates/terminal_view`，Standalone 终端。

## 目标

把常用短语一键送进当前终端，不必每次重打。主要用在 agent 的输入框上。

## 入口

- 固定在终端右下角的浮动按钮组里，位置在「插入文件」左侧（`right = 124px`），图标为闪电，与另两个按钮同为 40px 圆钮。
- 悬停提示「Quick Input」，并附带快捷键（由 `Tooltip::for_action_title` 从 keymap 取）；另两个按钮的提示为 `Insert Files`、`Bottom`。
- 快捷键 `Ctrl+Alt+Z`（Terminal 上下文）。

## 为什么不用光标定位

最初的方案是贴着终端光标放按钮。实测放弃：

- agent 的输入框由 CLI 自绘（反色块），真终端光标被 CLI 隐藏（`\x1b[?25l`），位置也常停在内部布局处，与肉眼看到的输入框相差很远。
- herdr 转发的是真光标坐标，不是自绘光标；两者不是一回事。
- 依赖「光标可见」的判定在 agent 场景下直接失效（`shape_hidden=true`）。

因此按钮固定在底部，不再解析光标，也不再依赖任何 agent 或 pane 识别。

## 弹窗

- 点击按钮或按快捷键打开；居中显示，宽度为窗口宽度的 2/5（不小于 280px），最高为窗口高度的 60%，超出滚动。
- 打开时焦点直接进入顶部输入框，键盘可立即使用。
- 右上角有关闭按钮（×），悬停提示「关闭 (Esc)」。
- 键盘：↑↓ 切换选中、回车执行、Esc 关闭。↑↓/回车走 `QuickInput` 上下文的键绑定；Esc 由 `cx.intercept_keystrokes` 拦截——`editor::Cancel` 绑定在编辑器上下文里且优先级更高，只有按键拦截器能可靠地先拿到它。拦截器仅弹窗打开期间存在，且只在弹窗自己的输入框持有焦点时生效。弹窗打开期间终端不再向 pty 转发按键。
- 鼠标：单击选中，双击直接发送。

## 顶部输入框

- 有文字时按回车：把这段文字存为一条新的快捷语（若在编辑某条，则保存为修改）。
- 输入框为空时按回车：把当前选中的条目发送到终端。
- 保存后输入框清空，焦点留在弹窗里，再按一次回车即发送刚加的那条。
- 输入框下方一行是「直接执行」勾选项（`Run immediately`），默认勾选：勾选时发送会在粘贴文本后另发一个 `\r` 让终端立即执行；取消勾选则只插入文本。回车必须单独写：放在 bracketed paste 内容里会被当成粘贴的换行而不是提交。

## 条目

- 每行悬停显示编辑（铅笔）与删除（垃圾桶），提示分别为 `Edit`、`Delete`。
- 编辑：该行原地变成文本框，回车保存、Esc 取消，不跳到顶部输入框。
- 删除：立即从列表与磁盘移除。
- 选中态使用主题的 `border_focused` 焦点边框，与设置页里键盘可达控件的样式一致，随主题变化。
- 长文本自动换行显示，行高随内容增长；列表是滚动视口，更高的行只需滚动查看。

## 发送

写入 pty，走 `Terminal::paste`。默认（直接执行勾选）之后再单独写 `\r`；取消勾选则只插入不提交。内容含换行时由终端自行加 bracketed paste 包裹，避免被当成多次提交。发送后关闭弹窗，焦点还给终端。

## 持久化

- 文件：`paths::data_dir()/terminal/quick-inputs.json`（`terminal` 子目录在首次写入时创建）。
- 结构：`{ "version": 1, "items": ["...", "..."] }`。
- 写入：变更后整体原子写（临时文件 + rename）；解析失败或超大文件不覆盖，避免把读故障变成数据丢失。
- 读取：首次使用懒加载，全局共享一份；每次打开弹窗重新读一次，这样手改文件无需重启即可生效，读取失败的文件在修好后也不会被永久拒绝写入。逐条宽松解析，脏条目跳过而不是整份丢弃。
- 列表滚动：条目直接挂在滚动容器下（`ScrollHandle::scroll_to_item` 只索引直接子元素）；新增条目用 `scroll_to_bottom`，在 prepaint 阶段按刷新后的内容高度定位。

## 文件校验与上限

文件允许用户直接编辑，所以按不可信输入处理：

- 单条上限 2000 个字符，超长截断（不丢整条）。
- 列表上限 200 条，超出的尾部丢弃并记日志。
- 文件上限 1 MiB，超限视为损坏，不读也不覆盖。
- 剥离控制字符：`ESC`、`BEL` 等会被终端当成控制序列，粘贴时会执行而不是当作文本；换行与制表符保留。
- 全部规则都有单元测试：控制字符、截断、超大文件、非字符串条目、条数上限、非对象 JSON。

## 文案与本地化

界面文案全部是英文源串，并通过 `localization::localized_str!` 取词，不在代码里写死中文。

新增的 4 条词（`Quick Input`、空态提示、`Close (Esc)`、`Insert Files`）已手工补进全部 13 个语言包（`Bottom` 原本就有）；en-US 用源串本身。

`catalog_sha256` 只校验 index 与 bundle 是否同批生成，加载时不比对内容，所以手工加词条不会触发英文回退；下次跑 `zed-i18n extract` 时会以源码为准重新生成，手工条目会被合并或覆盖。

## 快捷键

| 范围 | 按键 | 动作 |
| --- | --- | --- |
| Terminal | `Ctrl+Alt+Z` | 打开/关闭快捷输入 |
| Terminal | `Ctrl+Alt+O` | 插入文件路径 |
| 弹窗内（捕获阶段） | `↑` / `↓` | 切换选中 |
| 弹窗内（捕获阶段） | `Enter` | 添加 / 发送 |
| 弹窗内（捕获阶段） | `Esc` | 关闭 |

OHOS 的 `keymaps/default-ohos.json` 里这两个组合原本都空着，不涉及删除上游绑定。

## 边界

- 只读终端不显示按钮、不响应快捷键。
- 快捷语为空时，弹窗显示空态提示，回车无条目可发送。
- 列表打开期间 pty 仍在输出，不影响弹窗。

## 验收

1. 终端右下角、插入文件按钮左侧有闪电，悬停有提示。
2. 点击或 `Ctrl+Alt+Z` 打开居中弹窗，可直接打字。
3. 输入文字回车 → 列表新增；再回车 → 文字进入终端，弹窗关闭。
4. 双击条目 → 进入终端，弹窗关闭。
5. ↑↓ 切换选中，回车发送当前项。
6. Esc 或右上角 × 关闭弹窗。
7. 重启应用后条目仍在。
8. `Ctrl+Alt+O` 打开文件选择并插入路径。
